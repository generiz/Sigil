# Guided protocol playback

The demo executes the Sigil Rust/WASM core at normal speed. A configurable visual delay can replay the same real result stage by stage for explanation purposes.

Stages shown:

1. Secure Canvas bytes and ephemeral SymbolId representation.
2. Inner and outer authenticated encryption.
3. Reed–Solomon fragmentation.
4. Simulated node distribution using real generated shards.
5. Reconstruction, authentication and receiver rendering.

The delay affects visualization only; it does not slow or alter the cryptographic operations.
